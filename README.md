# Chapter-23

This repository contains Java code for "Chapter 23".

## Description

Small collection of Java examples and exercises for Chapter 23.

## Requirements

- Java 8 or later

## Build & Run

If the repository uses a build tool (Maven/Gradle), use that tool. Otherwise you can compile and run with the JDK:

Compile:

```
javac -d out $(find . -name "*.java")
```

Run (replace `com.example.Main` with the actual main class):

```
java -cp out com.example.Main
```
